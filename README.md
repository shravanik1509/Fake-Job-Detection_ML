# 🚨 Fake Job Detection using Machine Learning

## 📌 Project Overview
This project detects whether a job posting is **Fake or Real** using Machine Learning and Natural Language Processing (NLP).

## 🚀 Features
- Detects fraudulent job postings
- Uses job title and description
- High accuracy model using Logistic Regression

## 🧠 Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression

## 📂 Files
- app.py → Main prediction script
- fake_job_model.pkl → Trained ML model
- vectorizer.pkl → Text vectorizer

## ▶️ How to Run
1. Install dependencies:
   pip install scikit-learn

2. Run the script:
   python app.py

## 💡 Example
Input:
"Earn money from home easily"

Output:
Fake Job ❌

## 📈 Result
Achieved high accuracy in detecting fake job postings.
