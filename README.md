# 🚨 Fake Job Detection using Machine Learning

This project is a Machine Learning web application that detects whether a job posting is **real or fake** using Natural Language Processing (NLP).

It is deployed as a simple interactive web app using **Streamlit**.

---

## 📌 Problem Statement

Online job scams are increasing rapidly. This project helps users identify fake job postings using AI-based text classification.

---

## ⚙️ Features

- 🧠 Machine Learning model for classification
- 📝 Text input for job description
- ⚡ Real-time prediction (Fake or Real)
- 🌐 Web app interface using Streamlit
- 📊 NLP-based text processing

---

## 🛠️ Tech Stack

- Python 🐍
- Pandas & NumPy
- Scikit-learn
- NLP (TF-IDF Vectorizer)
- Streamlit (UI)
- Pyngrok (for deployment)

---

## 🚀 How it Works

1. User enters job description
2. Text is cleaned and vectorized
3. ML model predicts output
4. Result is displayed:
   - 🚨 Fake Job
   - ✅ Real Job
